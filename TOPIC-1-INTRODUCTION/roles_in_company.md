
Business & Strategy

A Business Analyst (BA) talks to the client or business to understand what problem needs to be solved. They translate business needs into clear requirements for the tech team. 

A Product Manager (PM) decides what product to build, why, and when — they own the big picture and the roadmap. A Product Owner (PO) works closely with the development team, managing the list of tasks (called a backlog) and deciding what gets built first.



Design & Build

A Software Architect designs the overall structure of the system — like an engineer drawing blueprints before a building is constructed.

 Developers write the actual code that makes the software work. 
 
 Technical Writers write the documentation, user manuals, and guides so people know how to use the software.



Quality & Data

A QE Engineer (Quality Engineer) tests the software to find bugs before it reaches users — they are the last line of defence before release.

 A DBA (Database Administrator) manages the database — making sure data is stored safely, efficiently, and is always available.



Operations & Delivery

A DevOps Engineer automates the build, testing, and deployment pipeline — making releases faster and more reliable. 

A Release Manager controls when and how new software versions are released to the public, coordinating all teams.

 An SRE (Site Reliability Engineer) monitors the live system 24/7 to make sure it stays fast, stable, and available to users.
