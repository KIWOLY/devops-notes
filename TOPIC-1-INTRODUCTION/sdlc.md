software development life cycle (SDLC)
    is the set of standard that is dollowed to the software industry to design , develop and to test 

    main  steps are 
     planning(requirements) ->defining (Software requiremnet specification)-> designing  ->developing -> testing -> deploy 


which  part in the SDLC devops take part 
      building ->  testing -> deploy         (automation)


Building --> Building means converting the code that developers wrote into a working software program that a computer can actually run.

What happens during building:
1. Compiling
Human code → machine
language the PC understands
2. Linking
Combines code files
and libraries together

3. Packaging
Bundles everything into
one installable file


Testing --> Testing is the process of checking that the software works correctly before it is released to users.
it primary role of the QE engineers

The 4 main types of testing:
1. Unit testing  Tests one small piece of code at a time
2. Integration Tests parts working together correctly
3. Regression Checks old features still work after changes
4. System test Tests the whole app end to end
 

Deployment --> make software to be availavle to the customer /user

   fastern the process of delivery  of the software   from building testing and deployment are followed without manual intervision -(everything is automated)


What to add: DevOps also covers:

Monitor — after deployment, DevOps tools watch the live system for     errors,      crashes, slow performance, and send alerts automatically

Planning — DevOps teams use feedback from monitoring to inform the next round of planning (this is the "loop" that makes DevOps a cycle, not just a straight line)
